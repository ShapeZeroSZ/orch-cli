Orch CLI

Run shell commands one after another or all at once, with clear per-task results and a meaningful exit code.

Install

pipx install git+https://github.com/ShapeZeroSZ/orch-cli

Use

orch run "git pull" "npm install" "npm test"
orch run "npm run lint" "npm test" --parallel
orch run -p -j 2 -t 600 -q "pytest" "ruff check ." "mypy src"
  • Sequential runs stop at the first failure (or --keep-going)
  • Parallel output is grouped per task, never interleaved
  • Per-task timeouts that kill the whole process tree
  • Exit code 1 if anything failed, so it works in scripts and CI
